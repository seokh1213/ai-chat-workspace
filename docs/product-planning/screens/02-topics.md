# 02. 주제 / Topics Workspace List

## 1. 화면 목적

`주제` 화면은 오래 살아 있는 작업공간을 찾고, 현재 상태를 훑고, 필요한 경우 바로 대화하거나 전체 작업실로 진입하는 허브다. PRD의 원칙상 단발 질문은 채팅에서 끝나지만, 여행 계획·투자 리서치·글쓰기·리서치·자동화처럼 계속 다듬는 대상은 `topic`으로 저장된다. 이 화면은 그 지속 작업의 목록, 진행률, 다음 액션, 관련 기억, 최근 활동을 한 번에 보여준다.

핵심 목적은 세 가지다.

| 목적 | 설명 |
| --- | --- |
| 지속 작업 탐색 | 검색, 유형 필터, 상태 필터로 기존 주제를 빠르게 찾는다. |
| 작업 상태 파악 | 카드와 우측 상세 패널에서 진행률, 다음 할 일, 연결 자료, 최근 활동을 확인한다. |
| 적절한 표면 선택 | 가벼운 질문은 `빠른 채팅`, 본격 편집은 `작업실 열기`로 분리한다. |

## 2. 화면 범위와 전제

- 이 문서는 첨부 이미지와 `/docs/personal-agent-platform-prd.md` 기준의 PC 웹 화면 상세다.
- 소유 범위는 `주제 목록 + 우측 상세 패널`이다. 좌측 글로벌 내비게이션은 공통 셸로 보되, 이 화면에서 보이는 상태와 전환 요구사항은 함께 기록한다.
- MVP에서는 여행 주제가 가장 높은 우선순위다. 다만 화면 구조는 투자, 글쓰기, 리서치, 자동화, 일정형 주제를 같은 카드 모델로 수용해야 한다.
- 목록 화면에서 주제를 편집하지 않는다. 편집성 작업은 빠른 채팅에서 제안까지만 하거나 `작업실 열기` 후 작업면에서 수행한다.

## 4. 진입 / 종료 / 전환 동선

### 4.1 진입 동선

| 진입점 | 동작 |
| --- | --- |
| 좌측 내비게이션 `주제` 클릭 | 마지막 목록 조건과 마지막 선택 주제를 복원한다. 없으면 전체 목록과 최근 사용 주제를 선택한다. |
| 오늘 화면의 최근 주제 카드 클릭 | 해당 주제를 선택한 상태로 `주제` 화면에 진입한다. 가능한 경우 우측 상세 패널을 열어 둔다. |
| 전역 채팅에서 “저번에 작업하던 여행 목록 보여줘” | `list_topics(type=travel)` 결과를 표시하고, 사용자가 목록 화면 보기를 선택하면 이 화면으로 이동한다. |
| 기억/스크랩/파일에서 “주제에 연결” 후 이동 | 연결 대상 주제를 선택하거나 생성하기 위해 이 화면을 모달 또는 전체 화면으로 사용한다. |
| URL 직접 접근 | `topicId`가 있으면 해당 주제 선택, 없으면 기본 목록 표시. 권한 없거나 삭제된 주제면 에러 상태 표시. |

### 4.2 종료 동선

| 종료 액션 | 결과 |
| --- | --- |
| 좌측 메뉴 이동 | 현재 검색어, 필터, 선택 주제, 스크롤 위치를 세션 범위에서 보존한다. |
| `작업실 열기` | 선택 주제의 전체 작업실로 이동한다. 이후 대화와 작업면 변경은 해당 주제 scope에 귀속된다. |
| 빠른 채팅에서 외부 링크/자료 열기 | 필요 시 새 탭 또는 해당 상세 화면으로 이동한다. 원래 주제 선택 상태는 유지한다. |
| 브라우저 뒤로가기 | 이전 화면 또는 이전 목록 조건으로 복귀한다. 필터 변경은 히스토리에 반영할지 결정 필요. |

| 탭 전환 | 개요/채팅/자료/일정/설정 클릭 | 상세 패널 내부에서만 전환한다. 중앙 목록은 유지한다. |

| 페이지 이동 | 이전/다음/페이지 번호 | 현재 검색/필터 조건을 유지하고 다음 결과 묶음을 로드한다. |

## 5. 핵심 시나리오

### 5.1 기존 여행 주제를 찾아 이어서 작업

1. 사용자가 좌측 메뉴에서 `주제`를 연다.
2. 최근 선택 주제 또는 가장 최근 업데이트된 `도쿄 여행`이 우측 패널에 표시된다.
3. 카드에서 진행률 75%, 다음 액션 `2일차 일정 최적화`, 날짜 `오늘`을 확인한다.
4. 사용자가 우측 빠른 채팅에 “2일차 동선을 덜 빡세게 바꿀 수 있어?”라고 입력한다.
5. AI는 주제 scope의 자료와 최근 활동을 참조해 짧은 제안을 반환한다.
6. 사용자가 실제 일정표와 지도까지 수정하려면 `작업실 열기`를 누른다.

### 5.2 새 주제 만들기

1. 사용자가 `새 주제 만들기`를 클릭한다.
2. 생성 플로우에서 유형, 이름, 설명, 대표 이미지, 초기 자료 연결 여부를 입력한다.
3. 생성 완료 후 목록 첫 위치 또는 최근 정렬 위치에 카드가 추가된다.
4. 우측 상세 패널은 새 주제를 선택하고, 빠른 채팅 placeholder는 새 주제명 기준으로 바뀐다.
5. 템플릿이 있는 유형은 작업실 첫 진입 시 기본 작업면을 준비한다.

### 5.3 검색과 필터로 특정 주제 찾기

1. 사용자가 검색창에 `NVDA`를 입력한다.
2. 제목, 설명, 다음 액션, 연결 자료에서 매칭된 주제를 보여준다.
3. 사용자가 `투자` 필터를 누르면 투자 유형 안에서만 결과가 재계산된다.
4. 결과가 0개면 빈 상태에서 `새 투자 주제 만들기`와 `전체 검색으로 보기`를 제공한다.

### 5.4 빠른 채팅으로 가벼운 확인

1. 사용자가 카드 선택 후 우측 패널의 `바로 채팅하기` 입력창에 질문한다.
2. 답변은 우측 패널의 채팅 탭 또는 최근 활동에 기록된다.
3. 답변이 자료 연결, 일정 변경, 예약 작업 생성처럼 쓰기 액션을 요구하면 승인 카드 또는 작업실 이동 CTA를 먼저 보여준다.
4. 짧은 답변, 요약, 비교는 목록 화면을 벗어나지 않고 끝낸다.

### 5.5 작업실 열기로 본격 편집

1. 사용자가 `작업실 열기`를 클릭한다.
2. 앱은 선택된 `topicId`를 active topic으로 설정한다.
3. 주제 공통 셸 또는 유형별 작업면으로 이동한다.
4. 여행이면 일정/지도, 글쓰기면 문서, 투자면 차트/리서치 보드처럼 작업면이 열린다.
5. 이후 채팅, 자료, artifact, schedule, run은 해당 주제에 귀속된다.

## 6. 컴포넌트별 상세 기능

| 사용자 카드 | 사용자명, 플랜, 계정 메뉴, 플랜/비용 화면 진입. |

### 6.2 화면 헤더

| 요소 | 기능 |
| --- | --- |
| 제목 `주제` | 현재 페이지의 최상위 제목. |
| 보조 문구 | “계속 다듬고, 확장하고, 완성해가는 나만의 작업 공간입니다.” |

### 6.3 검색/필터 바

| 요소 | 기능 |
| --- | --- |
| 검색 입력 | 주제명, 설명, 유형, 다음 액션, 연결 기억 이름, 최근 활동 텍스트 검색. |
| 단축키 힌트 `⌘K` | 포커스 이동 또는 전역 검색 열기. 실제 동작 범위 확정 필요. |
| 유형 필터 | 전체, 여행, 투자, 글쓰기, 리서치, 자동화. 선택 시 URL query 또는 상태에 반영. |
| 필터 버튼 | 상태, 진행률, 마감일, 연결 자료, 자동화 유무, 최근 활동, 정렬 기준 설정. |

### 6.4 주제 카드

카드는 목록 스캔과 선택을 위한 핵심 단위다. 카드 클릭은 우측 상세 패널 갱신이고, 더블클릭 또는 명시 액션은 작업실 열기로 연결할 수 있다.

| 요소 | 기능 |
| --- | --- |
| 대표 이미지 | 유형별 기본 이미지 또는 사용자가 설정한 cover image 표시. 이미지가 없으면 유형별 fallback 사용. |
| 유형 배지 | 주제 템플릿과 색상 매핑. 예: 여행 파랑, 투자 초록, 글쓰기 보라, 리서치 파랑, 일정 초록. |
| 오버플로 메뉴 | 이름 변경, 고정, 보관, 삭제, 공유, 설정, 작업실 열기. 위험 액션은 확인 필요. |
| 제목/아이콘 | 주제명과 이모지 또는 아이콘 표시. 긴 제목은 2줄 이하로 말줄임. |
| 설명 | 주제 목적 또는 AI 요약. 없는 경우 최근 목표나 생성 목적 표시. |
| 진행률 | 0-100%. 목표 기반, 체크리스트 기반, 또는 사용자가 직접 설정한 값. 산출 근거는 상세 패널에서 확인. |
| 메타 카운트 | 대화 수, 연결 자료 수, 북마크 또는 artifact 수. 권한 제한 자료는 개수에 포함하되 접근 시 제한 표시. |
| 다음 액션 | 가장 가까운 task, AI 제안, 일정, 예약 run 중 하나를 표시. |
| 날짜 | 다음 액션의 마감일, 예정일, 또는 상대 날짜. 시간대는 사용자 로컬 기준. |

### 6.5 카드 오버플로 메뉴

| 액션 | 동작 |
| --- | --- |
| 작업실 열기 | 해당 topic workspace로 이동. |
| 빠른 채팅 | 우측 패널의 채팅 입력에 포커스. |
| 이름/설명 수정 | 인라인 또는 설정 모달에서 수정. |
| 고정/고정 해제 | 목록 상단 또는 별도 고정 섹션에 반영. |
| 보관 | 기본 목록에서 숨김. 검색/필터에서 보관 포함 시 표시. |
| 삭제 | 연결 자료, run, schedule 영향 범위를 보여준 뒤 승인. 실제 삭제 정책은 확정 필요. |

### 6.6 우측 상세 패널

선택된 주제의 미리보기와 즉시 작업 영역이다. 첨부 화면에서는 `도쿄 여행`이 선택되어 있다.

| 요소 | 기능 |
| --- | --- |
| 주제 헤더 | 제목, 아이콘, 알림/핀 아이콘, 더보기 메뉴. |
| 진행률 바 | 카드와 동일한 진행률을 넓은 바와 퍼센트로 표시. |
| 탭 | 개요, 채팅, 자료, 일정, 설정. |
| 최근 활동 | 주제 scope에서 발생한 대화, AI 제안, 스크랩 추가, 비교/분석, 체크포인트를 시간순 표시. |
| `모두 보기` | 전체 활동 타임라인 또는 작업실 내 활동 탭으로 이동. |
| 연결된 기억 | 관련 기억/스크랩/파일 목록과 항목별 count 표시. |
| 빠른 채팅 | 선택 주제 scope로 짧은 질문을 보낸다. |
| 작업실 열기 | full workspace 진입. 외부 링크 아이콘으로 화면 전환을 명확히 표현. |

### 6.7 상세 패널 탭

| 탭 | 내용 |
| --- | --- |
| 개요 | 최근 활동, 연결된 기억, 빠른 채팅, 작업실 열기. 기본 탭. |
| 채팅 | 해당 주제에 귀속된 최근 대화 요약과 새 메시지 입력. 긴 대화는 작업실로 유도. |
| 자료 | 연결된 기억, 스크랩, 파일, URL, YouTube, 문서 목록. 연결/해제는 권한 확인 후 수행. |
| 일정 | 다음 액션, calendar event, schedule, 마감일, 반복 작업 요약. |
| 설정 | 주제명, 설명, 유형, 대표 이미지, 권한, 알림, 보관/삭제 진입. |

### 6.8 빠른 채팅

빠른 채팅은 목록 화면을 떠나지 않고 선택 주제에 대해 가벼운 질문을 하는 기능이다.

| 항목 | 요구사항 |
| --- | --- |
| scope | `topic chat`으로 저장하되 UI는 상세 패널에 제한한다. |
| 용도 | 짧은 질의, 요약, 비교, 다음 액션 추천, 자료 위치 확인. |
| 제한 | 대규모 artifact 편집, 지도/문서/표 직접 수정, 장시간 run은 바로 실행하지 않는다. |
| 쓰기 작업 | 일정 변경, 외부 계정 쓰기, 파일 삭제, 예약 생성은 승인 또는 작업실 이동을 요구한다. |
| 결과 기록 | 답변, 제안, 사용한 자료, 실패는 최근 활동에 남긴다. |
| placeholder | 선택 주제명 포함. 예: “도쿄 여행에 대해 무엇이든 물어보세요...” |

### 6.9 작업실 열기

작업실 열기는 선택 주제를 full workspace로 승격하는 명시 액션이다.

| 항목 | 요구사항 |
| --- | --- |
| 목적 | 채팅 결과가 실제 작업면, artifact, 일정, 지도, 문서, 표로 펼쳐지는 환경 진입. |
| 전환 | active topic을 설정하고 주제 공통 셸 또는 유형별 작업면으로 이동. |
| 권한 | 접근 권한 확인. 읽기 전용 주제면 편집 버튼 비활성 또는 승인 요청. |
| 초기 탭 | 마지막 작업면을 복원한다. 없으면 유형 기본 작업면을 연다. |
| 실패 | 주제가 삭제/보관/권한 변경된 경우 목록에 머물고 상세 패널에 원인 표시. |

### 6.10 빠른 채팅과 작업실 열기 차이

| 구분 | 빠른 채팅 | 작업실 열기 |
| --- | --- | --- |
| 표면 | 우측 상세 패널 내부 | 전체 주제 작업실 |
| 목적 | 확인, 요약, 짧은 제안 | 실제 편집, 구조화, 산출물 관리 |
| 작업 시간 | 짧은 상호작용 | 길게 이어지는 작업 |
| 결과 | 채팅 답변, 작은 제안, 활동 기록 | artifact, 일정/지도/문서/표/할 일 변경 |
| 상태 변경 | 기본은 읽기/제안. 쓰기는 승인 필요 | 주제 데이터와 작업면을 직접 갱신 가능 |
| 사용 예 | “시부야 맛집 자료 어디 있어?”, “2일차 문제점만 요약해줘” | “일정표를 열어 2일차 동선을 재배치”, “여행 지도와 체크리스트 편집” |
| 실패 처리 | 패널 안에서 재시도/작업실 이동 제안 | 작업실 내 에러 상태와 복구 액션 제공 |

## 7. 상태 / 빈 상태 / 로딩 / 에러 / 권한 / 승인 / 비용 Edge Case

### 7.1 목록 상태

| 상태 | UI 요구사항 |
| --- | --- |
| 기본 | 카드 6개 단위 그리드, 선택 카드와 우측 패널 표시. |
| 검색 결과 있음 | 검색어와 필터를 유지하고 결과 수 표시. 매칭 텍스트 강조 여부 검토. |
| 전체 빈 상태 | “아직 주제가 없습니다” 메시지, 새 주제 만들기, 오늘 채팅에서 시작하기 CTA 제공. |
| 검색 빈 상태 | 검색어 기준 결과 없음, 필터 초기화, 전체 검색, 새 주제 생성 CTA 제공. |
| 유형 빈 상태 | 해당 유형 템플릿으로 새 주제 만들기 CTA 제공. |
| 보관만 있음 | 보관된 주제 보기 필터 제공. |
| 페이지 범위 초과 | 마지막 유효 페이지로 이동하거나 빈 페이지 대신 이전 페이지 표시. |

### 7.2 로딩 상태

| 대상 | UI 요구사항 |
| --- | --- |
| 최초 진입 | 카드 skeleton, 우측 패널 skeleton, 필터 비활성. |
| 검색/필터 | 기존 목록을 유지하고 바 상단 또는 카드 영역에 부분 로딩 표시. |
| 카드 이미지 | 이미지 skeleton 또는 유형별 fallback. 이미지 실패 시 재시도하지 않고 fallback 표시. |
| 상세 패널 | 선택 카드 정보는 즉시 표시하고 활동/기억은 부분 skeleton. |
| 빠른 채팅 응답 | 입력 잠금 또는 중복 전송 방지, 취소 가능 여부 검토. |

### 7.3 에러 상태

| 상황 | 처리 |
| --- | --- |
| 목록 조회 실패 | 재시도 버튼, 네트워크 상태 안내, 이전 캐시가 있으면 읽기 전용으로 표시. |
| 상세 조회 실패 | 우측 패널에 실패 메시지와 재시도. 중앙 목록은 유지. |
| 빠른 채팅 실패 | 메시지 단위 재시도, 사용된 모델/도구 실패 원인 요약. |
| 작업실 열기 실패 | 목록에 머물고 권한/삭제/네트워크/초기화 실패 중 원인 표시. |
| 이미지 로드 실패 | fallback 썸네일 사용. 카드 전체 실패로 보지 않는다. |
| 일부 카운트 조회 실패 | `-` 또는 보류 표시. 카드 클릭과 작업실 진입은 가능해야 한다. |

### 7.4 권한 상태

| 상황 | 처리 |
| --- | --- |
| 읽기 가능/편집 가능 | 모든 카드 정보와 작업실 편집 가능. |
| 읽기 전용 | 카드와 상세는 표시하되 수정, 삭제, 일정 변경, 자료 해제는 비활성. |
| 부분 권한 | 제한된 기억/파일은 제목 마스킹 또는 잠금 아이콘 표시. count는 정책에 따라 표시. |
| 주제 권한 없음 | 목록에 표시하지 않는 것이 기본. 직접 URL 접근 시 권한 없음 상태. |
| 연결 끊김 | 해당 연결 기반 자료/자동화에 경고 배지 표시. 재연결 동선 제공. |

### 7.5 승인 상태

| 승인 필요 작업 | 처리 |
| --- | --- |
| 외부 계정 쓰기 | 대상 서비스, 변경 내용, 권한 scope를 승인 카드로 표시. |
| 일정/예약 자동화 생성 | 반복 주기, 다음 실행 시간, 예상 비용, 중지 방법을 보여준 뒤 승인. |
| 파일 삭제/기억 삭제 | 영향받는 주제, 대화, artifact, run을 보여준 뒤 확인. |
| 비용 한도 초과 가능 작업 | 예상 토큰/비용, 현재 한도, 대체 모델 옵션 표시. |
| 여러 담당에게 맡기기 | 실행 담당, 사용 도구, 예상 시간, 비용 상한, 중지 방법 승인. |

### 7.6 비용 Edge Case

| 상황 | 처리 |
| --- | --- |
| 빠른 채팅 예상 비용 낮음 | 별도 승인 없이 실행하되 월 한도 임계값 근접 시 경고. |
| 고비용 모델 필요 | 모델 변경 사유, 예상 비용, 저비용 대안 제시. |
| 월/일 한도 초과 | 전송 차단, 설정의 비용 한도 화면으로 연결. |
| 연결 API 과금 발생 | 외부 provider 또는 MCP 비용이 발생할 수 있음을 승인 카드에 표시. |
| 작업실 초기화 비용 | 템플릿 생성이나 자료 요약이 비용을 만들면 생성/진입 전에 명시. |

### 7.7 데이터 정합성 Edge Case

| 상황 | 처리 |
| --- | --- |
| 카드 진행률과 상세 진행률 불일치 | 상세 조회 값을 우선하고 카드 캐시를 갱신한다. |
| 다음 액션이 삭제됨 | 다음으로 가까운 task/schedule을 재계산. 없으면 “다음 액션 없음” 표시. |
| 연결 기억이 삭제됨 | 최근 활동에는 삭제 이력을 남기고 연결 목록에서는 제거 또는 삭제됨 표시. |
| 주제 유형 변경 | 기존 작업면 호환성을 확인하고, 호환 안 되는 artifact는 보관 또는 변환 필요. |
| 동시 편집 | 상세 패널에 최신 업데이트 알림을 표시하고 새로고침 또는 병합 정책 적용. |

## 8. 다른 화면과의 연계

| 대상 화면 | 연계 방식 |
| --- | --- |
| 오늘 | 최근 주제 카드, 전역 채팅에서 주제 목록 조회, 진행 중 작업 요약이 이 화면으로 연결된다. |
| 주제 작업실 | `작업실 열기`로 진입. 주제별 채팅, 작업면, 자료, 결과물, 자동화의 실제 편집 화면. |
| 기억 | 연결된 기억 목록에서 상세로 이동. 기억 화면에서 주제 연결/해제 가능. |
| 스크랩 | YouTube/기사/블로그/PDF 스크랩을 주제에 연결하면 카드 count와 상세 활동에 반영. |
| 맡긴 일 | 주제 관련 run, multi-agent run, schedule 실행 이력을 최근 활동과 일정 탭에 표시. |
| 캘린더 | 다음 액션 날짜, 일정, 반복 자동 작업이 캘린더 이벤트로 노출. |
| 할 일 | 다음 액션과 체크리스트가 task로 연결. 할 일 완료 시 진행률에 반영 가능. |
| 파일 | 연결 파일 count, 파일 요약, 권한 제한 상태를 상세 패널 자료 탭에 표시. |
| 에이전트 | 주제 전용 에이전트 또는 자동화 담당 에이전트가 설정/활동에 표시. |
| 연결 | 외부 서비스 연결 상태가 자료/자동화/빠른 채팅 가능 여부에 영향. |
| 설정 | 비용 한도, 승인 정책, 기본 모델, 알림 설정이 빠른 채팅과 작업실 진입에 적용. |

| `DELETE /topics/{topicId}` | 삭제 또는 soft delete. 영향 범위 확인 API와 분리 권장. |
| `GET /topics/{topicId}/summary` | 진행률, stats, next action, 최근 활동, 연결 기억을 한 번에 조회하는 패널용 집계. |
| `GET /topics/{topicId}/activities` | 최근 활동 timeline 페이지네이션. |
| `GET /topics/{topicId}/sources` | 연결된 기억/스크랩/파일 목록. |
| `POST /topics/{topicId}/chat/messages` | 빠른 채팅 전송. 필요 시 approval request 또는 workspace 이동 제안 반환. |
| `POST /topics/{topicId}/open` | lastOpenedAt 갱신, active topic 설정, 초기 작업면 결정. 클라이언트 라우팅과 결합 가능. |
| `GET /topics/{topicId}/impact` | 삭제, 보관, 유형 변경, 권한 변경 전 영향 범위 조회. |

## 10. 수용 기준

### 10.1 목록과 탐색

- 사용자는 `주제` 화면 진입 후 전체 주제 목록을 카드 그리드로 볼 수 있다.
- 검색어 입력 시 주제명, 설명, 다음 액션, 연결 자료 기준으로 결과가 좁혀진다.
- 유형 필터 선택 시 목록과 선택 주제가 일관되게 갱신된다.
- 필터 조건이 결과 0개일 때 원인과 다음 액션이 보인다.
- 페이지네이션은 현재 조건을 유지한다.

### 10.2 주제 카드

- 카드에는 유형 배지, 대표 이미지, 제목, 설명, 진행률, 대화 수, 연결 수, 북마크/산출물 수, 다음 액션, 날짜가 표시된다.
- 카드 클릭 시 우측 상세 패널이 해당 주제로 갱신된다.
- 카드의 진행률과 상세 패널의 진행률은 같은 기준을 사용한다.
- 카드 이미지 실패 또는 누락 시 유형별 fallback이 표시된다.
- 오버플로 메뉴의 위험 액션은 영향 범위 확인과 승인 없이 실행되지 않는다.

### 10.3 상세 패널

- 선택 주제의 제목, 진행률, 탭, 최근 활동, 연결된 기억, 빠른 채팅, 작업실 열기가 표시된다.
- 탭 전환은 중앙 목록 상태를 변경하지 않는다.
- 최근 활동은 AI 제안, 스크랩 추가, 비교/분석, 채팅을 구분해서 보여준다.
- 연결된 기억 항목은 상세 기억/스크랩/파일 화면으로 이동할 수 있다.
- 권한 제한 자료는 제한 상태를 명확히 표시한다.

### 10.4 빠른 채팅과 작업실 열기

- 빠른 채팅은 선택된 주제 scope로 저장된다.
- 빠른 채팅은 짧은 질의와 제안에 적합하며, 본격 편집이 필요한 경우 작업실 이동을 제안한다.
- 빠른 채팅에서 외부 쓰기, 예약, 고비용 실행, 삭제가 필요하면 승인 흐름이 먼저 나온다.
- `작업실 열기`는 active topic을 설정하고 유형별 작업면 또는 주제 공통 셸로 이동한다.
- 작업실 진입 실패 시 목록 화면을 유지하고 실패 원인을 보여준다.

### 10.5 상태와 안전

- 최초 로딩, 부분 로딩, 빈 상태, 검색 빈 상태, 목록 실패, 상세 실패, 채팅 실패가 각각 구분된다.
- 읽기 전용 주제에서는 수정성 액션이 비활성화된다.
- 비용 한도 초과 시 빠른 채팅 또는 자동화 실행이 차단되고 설정 화면으로 연결된다.
- 삭제/보관/유형 변경 전에는 연결 자료, run, schedule, artifact 영향 범위가 확인된다.
- 동시 편집 또는 캐시 불일치가 발생하면 최신 데이터 기준으로 복구할 수 있다.

## 11. 자체 Edge Case 리뷰

사용자가 nested subagent 리뷰를 요청했으므로 완료 전 읽기 전용 리뷰를 시도했다. sandbox 내부에서는 Codex app-server 초기화 권한 문제로 실패했고, 비샌드박스 재시도는 사설 문서 외부 전송 위험으로 차단되어 진행하지 않았다. 따라서 아래는 자체 edge case 리뷰 결과다.

| 검토 항목 | 확인 결과 |
| --- | --- |
| 이미지에 보이는 기능 누락 여부 | 좌측 내비, 알림, 사용자 플랜, 헤더, 새 주제 만들기, 검색, 유형 필터, 필터 버튼, 카드 6개, 페이지네이션, 우측 상세 패널, 탭, 최근 활동, 연결된 기억, 빠른 채팅, 작업실 열기를 반영했다. |
| 빠른 채팅/작업실 열기 구분 | scope, 목적, 결과, 상태 변경, 승인 필요 조건을 별도 표로 분리했다. |
| 상태 모델 | 목록, 로딩, 에러, 권한, 승인, 비용, 데이터 정합성 edge case를 분리했다. |
| 다른 화면 연계 | 오늘, 기억, 스크랩, 맡긴 일, 캘린더, 할 일, 파일, 에이전트, 연결, 설정과의 데이터 흐름을 명시했다. |
| 개발 착수 가능성 | API 힌트와 필드 힌트를 포함했지만, 실제 라우트명과 삭제 정책은 오픈 질문으로 남겼다. |
