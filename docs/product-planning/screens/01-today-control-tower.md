# 오늘 / Control Tower 화면 상세 기획

## 1. 화면 목적과 사용자 문제

오늘 화면은 개인형 Agent 플랫폼의 첫 진입점이다. 사용자가 메뉴 구조를 먼저 이해하지 않아도, 중앙 채팅에서 바로 요청을 시작하고 오른쪽 패널에서 이미 맡긴 일과 자동 작업의 진행 상태를 확인하는 Control Tower 역할을 한다.

이 화면이 해결해야 하는 사용자 문제는 다음이다.

| 사용자 문제 | 화면에서의 해결 방식 |
| --- | --- |
| 어디서 시작해야 할지 모름 | 중앙에 큰 전역 채팅 입력창과 빠른 의도 버튼을 배치 |
| 이전에 하던 작업을 다시 찾기 어려움 | 최근 주제 카드와 진행률, 마지막 활동 시간을 노출 |
| 맡긴 일이 실제로 진행 중인지 불안함 | 오른쪽에 진행 중인 맡긴 일 timeline을 상시 표시 |
| 반복 자동화가 켜져 있는지 기억하기 어려움 | 예정된 자동 작업 목록과 토글 상태를 표시 |
| 외부 연결/권한/비용 때문에 실행이 막히는 이유를 모름 | 연결 가이드, 승인 대기, 비용 제한 상태를 화면 안에서 안내 |

제품 원칙상 단발 요청은 채팅 안에서 끝나고, 지속 관리 대상은 주제로 승격되며, 장시간 실행/반복/다중 담당 작업은 맡긴 일로 이동한다. 오늘 화면은 이 세 흐름을 한 화면에서 시작하고 감시하는 시작점이다.

## 2. 정보 구조와 레이아웃

### 전체 레이아웃

PC 기준 3열 구조다.

| 영역 | 구성 | 목적 |
| --- | --- | --- |
| 좌측 사이드바 | 허브 선택, 알림, 전역 메뉴, 설정/도움말, 사용자 플랜 | 전체 화면 간 이동과 계정 상태 확인 |
| 중앙 메인 | 인사말, 새 주제 만들기, 전역 채팅, 빠른 의도, 추천 도구, 최근 주제 | 새 요청 시작과 최근 작업 재진입 |
| 우측 패널 | 진행 중인 맡긴 일, 예정된 자동 작업, 빠른 시작 가이드 | 실행 상태 감시와 설정 미비 보완 |

### 좌측 사이드바

상단에는 사용자 아바타와 `내 AI 허브` 드롭다운, 알림 아이콘을 둔다. 드롭다운은 개인 허브/팀 허브/워크스페이스 선택으로 확장 가능하다.

전역 메뉴는 다음 순서로 노출한다.

| 메뉴 | 연결 화면 | 현재 화면에서의 의미 |
| --- | --- | --- |
| 오늘 | 오늘 / Control Tower | 현재 선택 상태 |
| 주제 | 주제 목록 | 지속 작업공간 전체 보기 |
| 맡긴 일 | 맡긴 일 | 실행 중/예약/완료 run 관리 |
| 기억 | 기억 | 저장된 자료와 선호도 |
| 에이전트 | 에이전트 빌더 | 에이전트 생성/편집 |
| 연결 | 연결 | MCP, 외부 API, 모델 제공자 |
| 스크랩 | 스크랩 inbox | URL/파일/영상 임시 수집 |
| 캘린더 | 캘린더 | 일정과 반복 작업 |
| 할 일 | 할 일 | 실행 항목과 체크리스트 |
| 파일 | 파일 | 업로드/생성 파일 관리 |

하단에는 `설정`, `도움말`, 사용자 프로필 카드(`Minho`, `프로 플랜`)를 표시한다. 프로필 카드는 계정 메뉴, 결제/사용량, 플랜 변경으로 이어진다.

### 중앙 메인 영역

상단에는 `안녕하세요, 민호님! 👋` 인사말과 보조 문구 `계획하고, 조사하고, 만들어내고, 자동으로 처리까지. 무엇이든 물어보세요.`를 둔다. 오른쪽에는 `새 주제 만들기` 버튼을 배치한다.

핵심 입력 영역은 `무엇을 도와줄까요?` 카드다. 내부에는 메시지 입력창, 첨부/웹/도구 선택 아이콘, 음성 입력, 전송 버튼이 있다. 입력창 아래에는 빠른 의도 버튼을 둔다.

빠른 의도는 첨부 화면 기준 다음 5개를 기본값으로 한다.

| 빠른 의도 | 설명 | 기본 동작 |
| --- | --- | --- |
| 빠른 답변 | 질문에 빠르게 답변 | 전역 채팅 단발 응답 |
| 자료 정리 | 문서, 링크, 파일 정리 | 첨부 또는 스크랩 생성 유도 |
| 여행 계획 | 여행 일정과 정보를 작성 | 여행 주제 생성 또는 기존 여행 주제 추천 |
| 여러 담당에게 맡기기 | 여러 에이전트로 병렬 처리 | 맡긴 일 생성 플로우 진입 |
| 자동으로 해두기 | 반복 작업 자동화 | 자동 실행 등록 플로우 진입 |

추천 도구 영역은 채팅 결과를 다른 객체로 승격시키는 바로가기다.

| 추천 도구 | 화면 문구 | 동작 |
| --- | --- | --- |
| 작업면으로 펼치기 | 결과물을 지도, 문서, 표, 보드 등으로 보기 | 현재 대화 결과를 artifact/surface로 생성 |
| 주제로 저장 | 이 대화를 주제로 저장하고 계속 발전시키기 | topic 생성 후 conversation 연결 |
| 자료 스크랩 | 링크, 영상, 기사 등 저장하고 요약하기 | source 생성 후 memory/scrap에 저장 |
| 자동 실행 등록 | 스케줄, 알림, 모니터링 등록하기 | schedule 생성 플로우 진입 |

최근 주제 영역은 카드형 목록이다. 첨부 화면에는 `도쿄 여행`, `미국 주식 리서치`, `블로그 글쓰기` 3개 카드가 보인다. 각 카드는 썸네일, 제목, 설명, 상태, 진행률, 댓글/파일/스크랩 수, 마지막 활동 시간, 더보기 메뉴를 가진다. 하단에는 `더 많은 주제 보기` 버튼을 둔다.

### 우측 패널

우측 패널은 오늘 화면이 단순 채팅 홈이 아니라 Control Tower임을 보여주는 핵심 영역이다.

첫 번째 카드 `진행 중인 맡긴 일`은 현재 실행 중인 run을 timeline으로 보여준다. 헤더에는 카운트 배지와 `모두 보기` 링크를 둔다. 첨부 화면 기준 항목은 다음 형태다.

| 항목 예시 | 보조 설명 | 표시 정보 |
| --- | --- | --- |
| 도쿄 여행 조사 중 | 항공권/숙소/실내/교통 조사 | 진행률 65%, 2분 전 |
| 도쿄 맛집 리스트업 | 현지 인기 맛집 정리 중 | 진행률 40%, 5분 전 |
| AAPL, NVDA 리포트 분석 | 실적/전망 비교 분석 | 진행률 75%, 10분 전 |
| 블로그 초안 작성 | 글 초안 작성 및 구조화 | 진행률 25%, 25분 전 |

timeline 좌측에는 상태 점과 연결선을 표시한다. 각 항목은 실행 유형 아이콘, 제목, 설명, 진행률, 마지막 업데이트 시간, 담당 에이전트 아바타를 가진다. 표시 가능한 항목 수를 초과하면 `+2개 더 보기`처럼 접힘 링크를 제공한다.

두 번째 카드 `예정된 자동 작업`은 반복 schedule을 보여준다. 헤더에는 카운트 배지와 `모두 보기` 링크를 둔다. 각 항목은 아이콘, 제목, 설명, 반복 주기, 실행 시간, 활성 토글을 가진다. 첨부 화면 기준 항목은 `항공권 가격 모니터링`, `시장 리포트 요약`, `유튜브 영상 요약`, `주간 리뷰 알림`이다.

세 번째 카드 `빠른 시작 가이드`는 onboarding/설정 미비 보완 영역이다. 첨부 화면에는 `1/3` 진행 표시, 좌우 이동 버튼, `연결을 추가해 보세요` 안내, `연결 설정하기` 버튼이 있다. 가이드는 사용자의 연결/파일/첫 자동 작업 상태에 따라 개인화한다.

## 3. 진입/종료/전환 동선

### 진입

| 진입 경로 | 처리 |
| --- | --- |
| 로그인 후 첫 화면 | 오늘 화면으로 진입, 전역 채팅 입력창 focus 가능 |
| 다른 화면에서 사이드바 `오늘` 클릭 | 오늘 화면으로 이동, 최근 상태 재조회 |
| 브라우저 새로고침 | 마지막 선택 허브 기준 오늘 데이터 복원 |
| 알림 클릭 후 작업 확인 완료 | 관련 run/topic으로 이동하거나 오늘 화면 우측 패널에서 해당 항목 강조 |
| 외부 딥링크 실패 | 오늘 화면으로 fallback하고 오류 toast 표시 |

### 종료

| 종료 동작 | 처리 |
| --- | --- |
| 사이드바 메뉴 클릭 | 해당 화면으로 전환 |
| 최근 주제 카드 클릭 | 주제 공통 셸로 이동 |
| 진행 중인 맡긴 일 항목 클릭 | 맡긴 일 상세 또는 run timeline으로 이동 |
| 예정된 자동 작업 항목 클릭 | schedule 상세/편집으로 이동 |
| 새 주제 만들기 클릭 | 주제 생성 모달 또는 주제 생성 화면으로 이동 |
| 연결 설정하기 클릭 | 연결 화면으로 이동 |

### 화면 내 전환

채팅 입력 후 AI 응답 결과가 단발이면 중앙 채팅 카드 안에 답변을 표시한다. 결과가 지속 관리 대상이면 `주제로 저장`, `작업면으로 펼치기`, `자동 실행 등록`, `여러 담당에게 맡기기` 같은 승격 CTA를 노출한다.

사용자가 빠른 의도를 선택하면 입력창에 템플릿 문구를 채우거나 즉시 플로우를 연다. 예를 들어 `자동으로 해두기`는 반복 주기/실행 대상/승인 조건을 묻는 카드로 전환한다.

## 4. 핵심 시나리오와 happy path

### 시나리오 A. 단발 질문을 빠르게 처리

1. 사용자가 오늘 화면에 진입한다.
2. 중앙 입력창에 질문을 입력한다.
3. 전송 버튼을 누른다.
4. 시스템은 전역 conversation에 메시지를 저장하고 답변을 생성한다.
5. 답변이 짧은 Q&A로 판단되면 채팅 안에서 완료 처리한다.
6. 필요하면 답변 하단에 `주제로 저장`, `자료 스크랩`, `작업면으로 펼치기` CTA를 표시한다.

### 시나리오 B. 도쿄 여행 주제로 이어서 작업

1. 사용자가 최근 주제의 `도쿄 여행` 카드를 클릭한다.
2. 시스템은 topic 상세와 연결된 surface를 로드한다.
3. 주제 공통 셸로 이동하고, 이후 채팅 scope는 해당 topic으로 설정한다.
4. 오늘 화면의 최근 주제 카드는 마지막 활동 시간과 진행률을 갱신한다.

### 시나리오 C. 여러 담당에게 조사 맡기기

1. 사용자가 빠른 의도 `여러 담당에게 맡기기`를 누른다.
2. 입력 카드가 요청 범위, 담당 수, 산출물 형태를 묻는 상태로 바뀐다.
3. 사용자가 요청을 제출한다.
4. 시스템은 approval/cost 정책을 확인한다.
5. 승인 필요 없음 또는 승인 완료 시 run을 생성한다.
6. 우측 `진행 중인 맡긴 일` 최상단에 새 run이 추가되고 진행률이 갱신된다.
7. 완료 시 결과 요약과 관련 artifact/topic CTA를 제공한다.

### 시나리오 D. 반복 자동 작업 등록

1. 사용자가 `자동으로 해두기` 또는 추천 도구 `자동 실행 등록`을 선택한다.
2. 시스템은 반복 주기, 실행 시간, 사용할 연결/도구, 결과 전달 방식, 비용 제한을 묻는다.
3. 사용자가 등록한다.
4. 외부 API 또는 쓰기 권한이 필요하면 승인/연결 카드를 표시한다.
5. 등록 성공 시 `예정된 자동 작업` 목록에 새 schedule이 나타나고 토글은 켜짐 상태가 된다.

### 시나리오 E. 연결 미비를 해결

1. 사용자가 빠른 시작 가이드의 `연결 설정하기`를 클릭한다.
2. 연결 화면으로 이동한다.
3. 필요한 provider/MCP/OAuth 연결을 완료한다.
4. 오늘 화면으로 돌아오면 가이드 진행률이 갱신되고, 연결을 필요로 하던 추천 도구가 활성화된다.

## 5. 컴포넌트별 상세 기능

### 허브 헤더

| 요소 | 기능 |
| --- | --- |
| 사용자 아바타 | 계정 메뉴 진입 |
| `내 AI 허브` 드롭다운 | 허브/워크스페이스 선택 |
| 알림 아이콘 | 승인 대기, run 완료, 실패 알림 표시 |

허브가 변경되면 오늘 화면의 topic/run/schedule/source 범위가 해당 허브로 재조회된다.

### 사이드바 내비게이션

현재 메뉴는 파란색 활성 상태로 표시한다. 메뉴 클릭 시 라우팅만 수행하고, 오늘 화면 내부 입력 중인 draft가 있으면 임시 저장한다. 읽기 권한이 없는 메뉴는 숨기거나 비활성 표시한다.

### 인사말과 새 주제 만들기

인사말은 사용자 displayName을 사용한다. displayName이 없으면 `안녕하세요!`로 fallback한다. `새 주제 만들기`는 topic 생성 플로우를 열며, 생성 후 주제 화면으로 이동하거나 오늘 화면의 최근 주제 목록에 삽입한다.

### 전역 채팅 입력 카드

| 요소 | 기능 |
| --- | --- |
| 메시지 입력창 | 전역 conversation message 작성 |
| 첨부 아이콘 | 파일 업로드 또는 기존 파일 선택 |
| 웹 아이콘 | 웹 검색/URL 수집 모드 선택 |
| 도구 아이콘 | 사용 가능한 tool/agent 선택 |
| 음성 아이콘 | 음성 입력 시작/중지 |
| 전송 버튼 | 메시지 전송, 실행 생성 |

입력창은 빈 값일 때 전송 버튼을 비활성화한다. 첨부 파일만 있는 경우에는 파일 요약/정리 요청으로 전송 가능하다. 전송 중에는 중복 전송을 막고 중지 버튼 또는 진행 상태를 제공한다.

### 빠른 의도 버튼

빠른 의도는 사용자가 요청 문장을 만들기 전에 방향을 정하는 장치다. 선택 시 입력창 placeholder, 추천 도구, 필요한 필드가 바뀐다. 예를 들어 `여행 계획`은 목적지/일정/동행/예산 입력을 유도하고, `자료 정리`는 파일/URL 첨부를 우선 노출한다.

### 추천 도구 캐러셀

추천 도구는 현재 입력 또는 최근 대화 맥락에 따라 정렬한다. 화면 폭이 좁거나 항목이 많으면 우측 화살표로 넘긴다. 도구 실행 전 필요한 권한/연결/비용이 있으면 실행 대신 안내 카드를 표시한다.

### 최근 주제 카드

각 카드 필드는 다음이다.

| 필드 | 표시 |
| --- | --- |
| thumbnailUrl | 좌측 썸네일 |
| title | 제목 |
| subtitle | 주제 설명 또는 태그 |
| statusLabel | 진행 중, 검토 중, 초안 등 |
| progressPercent | 진행률 바와 숫자 |
| commentCount | 대화/댓글 수 |
| fileCount | 연결 파일 수 |
| sourceCount | 스크랩/기억 수 |
| lastActiveAt | 방금 전, 1시간 전, 어제 |
| overflowMenu | 이름 변경, 보관, 삭제, 공유 |

카드 클릭은 주제 상세 진입이다. 더보기 메뉴 클릭은 카드 클릭과 충돌하지 않아야 한다.

### 진행 중인 맡긴 일 카드

진행 중인 run을 최신 업데이트순으로 표시한다. 각 항목은 클릭 가능하며, 상세에서는 담당 agent, 단계별 로그, 산출물, 비용, 중지/재시도 액션을 확인할 수 있어야 한다.

진행률은 run 단계 기반으로 계산한다. 퍼센트가 불확실한 작업은 `조사 중`, `분석 중` 같은 단계 라벨을 함께 표시한다.

### 예정된 자동 작업 카드

schedule 목록은 활성 상태 우선, 다음 실행 시간순으로 정렬한다. 토글을 끄면 schedule은 비활성화되지만 삭제되지 않는다. 토글 변경에는 즉시 저장을 기본으로 하되 실패 시 원래 상태로 되돌리고 오류를 표시한다.

### 빠른 시작 가이드

가이드는 onboarding checklist다. 예시 단계는 `연결 추가`, `첫 주제 만들기`, `첫 자동 작업 등록`이다. 이미 완료한 단계는 건너뛰고 다음 미완료 단계를 보여준다. 닫기 기능이 있다면 사용자별 dismissed 상태를 저장한다.

## 6. 상태/빈 상태/로딩/에러/권한/승인/비용 edge case

### 공통 상태

| 상태 | 처리 |
| --- | --- |
| 초기 로딩 | 중앙 skeleton, 우측 카드 skeleton, 사이드바는 즉시 표시 |
| 부분 로딩 | 채팅/최근 주제/맡긴 일/자동 작업을 독립 로딩 |
| 새로고침 중 | 기존 데이터를 유지하고 각 카드에 작은 갱신 표시 |
| 오프라인 | 입력 전송/토글 변경 비활성, 마지막 캐시 데이터 표시 |

### 빈 상태

| 영역 | 빈 상태 문구/동작 |
| --- | --- |
| 최근 주제 없음 | `아직 주제가 없습니다. 채팅으로 시작하거나 새 주제를 만들어보세요.` |
| 진행 중인 맡긴 일 없음 | `진행 중인 맡긴 일이 없습니다.`와 `여러 담당에게 맡기기` CTA |
| 예정된 자동 작업 없음 | `자동으로 해둘 작업을 등록해보세요.`와 `자동 실행 등록` CTA |
| 연결 없음 | 빠른 시작 가이드에서 연결 설정 CTA 강조 |
| 파일/자료 없음 | 자료 정리 선택 시 업로드/URL 입력 유도 |

### 에러 상태

| 에러 | 처리 |
| --- | --- |
| 오늘 데이터 조회 실패 | 각 섹션별 재시도 버튼 제공 |
| 채팅 응답 실패 | 메시지는 draft/failed 상태로 남기고 재전송 가능 |
| run 생성 실패 | 실패 이유와 필요한 후속 액션 표시 |
| schedule 토글 실패 | 토글을 이전 값으로 복구하고 toast 표시 |
| 최근 주제 썸네일 실패 | 기본 아이콘/배경으로 fallback |
| 음성 입력 실패 | 텍스트 입력으로 fallback |

### 권한/승인

외부 서비스 조회, 파일 접근, 이메일/캘린더 쓰기, 예약 실행, 결제/비용 증가 가능 작업은 권한과 승인 정책을 확인한다.

| 상황 | 화면 처리 |
| --- | --- |
| 연결되지 않은 provider 필요 | 연결 카드 표시, `연결 설정하기`로 이동 |
| 읽기 권한 없음 | 해당 데이터 카드 숨김 또는 권한 요청 CTA |
| 쓰기 작업 승인 필요 | approval card 표시, 승인 전 실행 보류 |
| 팀 허브 정책상 자동 실행 금지 | 토글 비활성, 정책 안내 |
| 민감 파일 첨부 | 파일 권한 확인 후 전송 |

### 비용 edge case

| 상황 | 처리 |
| --- | --- |
| 단일 요청 예상 비용이 사용자 한도 초과 | 전송 전 비용 경고와 축소 옵션 제공 |
| 여러 담당 실행으로 비용 증가 가능 | 담당 수/모델/예상 비용 표시 후 승인 |
| 예약 작업 누적 비용 한도 초과 | schedule 생성 또는 활성화 차단 |
| 무료/하위 플랜 제한 | 프로 플랜 안내 또는 실행 범위 축소 |
| 실행 중 비용 급증 | run 일시 중지, 알림, 재승인 요청 |

### 자체 edge case 리뷰

서브에이전트 리뷰는 실행 오류로 완료되지 않아 자체 리뷰를 수행했다. 추가로 개발 시 확인할 포인트는 다음이다.

| 리뷰 포인트 | 확인 내용 |
| --- | --- |
| draft 보존 | 화면 전환/새로고침/허브 변경 시 입력 중 메시지 유실 여부 |
| 동시 상태 갱신 | run 진행률과 최근 주제 진행률이 서로 다른 API에서 갱신될 때 불일치 처리 |
| 토글 낙관 업데이트 | schedule 토글 실패 시 UI rollback과 중복 클릭 방지 |
| 카드 클릭 충돌 | 최근 주제 카드 클릭과 더보기 메뉴 클릭 이벤트 분리 |
| 권한 숨김 기준 | 권한 없는 데이터를 카운트에 포함할지 제외할지 결정 |
| 시간 표기 | `방금 전`, `1시간 전`, `어제`가 사용자 timezone 기준인지 확인 |
| 비용 승인 | 빠른 의도 버튼에서 바로 run을 만들지 않고 승인 단계를 거치는지 확인 |

## 7. 다른 화면과의 연계

| 대상 화면 | 연계 방식 |
| --- | --- |

| 맡긴 일 | 우측 진행 중 run 클릭, `여러 담당에게 맡기기`, run 완료 알림으로 진입 |

| 연결 | 빠른 시작 가이드, 연결 필요 오류, tool/provider 선택 시 연계 |
| 기억 | 스크랩이 정리되어 source/preference/decision으로 승격될 때 연계 |

| 캘린더 | 예약 작업의 실행 시간, 반복 일정, 일정 충돌 확인으로 연계 |

| 파일 | 첨부 파일 선택, 생성 artifact 다운로드/관리로 연계 |

## 9. 수용 기준

### 레이아웃/표시

- 오늘 화면은 좌측 사이드바, 중앙 메인, 우측 Control Tower 패널의 3열 구조로 표시된다.
- 좌측 사이드바에서 `오늘` 메뉴가 활성 상태로 보인다.
- 중앙 상단에 사용자 이름 기반 인사말과 `새 주제 만들기` 버튼이 표시된다.
- 중앙 채팅 카드에는 메시지 입력창, 첨부, 웹, 도구, 음성, 전송 액션이 표시된다.
- 빠른 의도 5개와 추천 도구 4개가 첨부 화면의 의미와 동일하게 표시된다.
- 최근 주제 카드는 썸네일, 제목, 설명, 상태, 진행률, 카운트, 마지막 활동 시간을 표시한다.
- 우측 패널은 진행 중인 맡긴 일, 예정된 자동 작업, 빠른 시작 가이드를 순서대로 표시한다.

### 동작

- 빈 메시지 전송은 불가능하다.
- 메시지 전송 성공 시 conversation에 메시지가 추가되고 응답 또는 실행 상태가 표시된다.
- 최근 주제 카드 클릭 시 해당 주제 화면으로 이동한다.
- `새 주제 만들기`는 주제 생성 플로우를 연다.
- 진행 중인 맡긴 일 항목 클릭 시 run 상세로 이동한다.
- 자동 작업 토글 변경은 서버 저장 결과와 동기화된다.
- 연결이 필요한 액션은 실행 전에 연결 화면 또는 승인 카드로 안내한다.

### 상태/권한/비용

- 최근 주제, 진행 중 맡긴 일, 예정 자동 작업은 독립적으로 로딩/에러/빈 상태를 표시한다.
- 권한이 없는 데이터는 노출하지 않거나 비활성 상태와 권한 안내를 표시한다.
- 비용 한도를 넘을 수 있는 실행은 시작 전에 예상 비용과 승인 CTA를 표시한다.
- 예약 작업이 비용 한도를 초과하면 등록 또는 활성화를 막는다.
- run 실패, schedule 토글 실패, 채팅 응답 실패는 재시도 가능해야 한다.

### 접근성/반응형

- 모든 아이콘 버튼은 접근 가능한 label을 가진다.
- 키보드로 사이드바, 입력창, 카드, 토글, CTA에 접근 가능하다.
- 좁은 화면에서는 우측 패널을 하단 섹션 또는 접이식 패널로 전환한다.
- 텍스트는 카드/버튼 영역에서 잘리지 않고 긴 제목은 2줄 말줄임 기준을 가진다.

| --- | --- |
