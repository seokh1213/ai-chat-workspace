# 12. 도움말 / Help 화면 상세 기획

## 1. 화면 목적

`도움말` 화면은 개인형 Agent 플랫폼을 처음 쓰는 사용자와 Dev Mode 사용자 모두가 필요한 사용법을 빠르게 찾고, 문서의 명령어를 그대로 실행하며, 문제가 생기면 도움말 봇과 시스템 상태로 원인을 좁히는 지원 허브다.

PRD 기준 `도움말`은 가이드, 명령어, Dev Mode 튜토리얼, 시스템 상태를 제공하는 화면이다. 첨부 화면 기준으로는 단순 문서 목록이 아니라 `검색 → 가이드 IA 선택 → 문서 읽기 → 명령어 복사 → 시스템 상태 확인 → 봇 문의/피드백`까지 한 화면 안에서 이어지는 작업형 도움말이다.

| 사용자 문제 | 화면에서의 해결 방식 |
| --- | --- |
| 어디서 어떤 기능을 배워야 할지 모름 | 좌측 가이드 IA를 `시작하기`, `채팅에서 주제로 이동`, `에이전트에게 맡기기`, `스크랩과 기억`, `모델/비용 관리`, `Dev Mode`로 구조화 |
| 원하는 문서를 바로 찾기 어려움 | 상단 검색창과 `⌘K` 단축키로 문서, 명령어, 업데이트, 상태 항목 통합 검색 |
| 로컬 TUI/MCP/API 연동을 따라 하기 어려움 | Dev Mode 문서에서 단계별 명령어, localhost endpoint, 터미널 예시, 보안 주의사항 제공 |
| 명령어를 오타 없이 실행하고 싶음 | 각 코드 블록 우측에 복사 버튼과 복사 성공/실패 상태 제공 |
| 문서가 최신인지 판단하기 어려움 | 문서별 카테고리, 읽기 시간, 최종 업데이트 일자, 신규/인기 배지, 최근 업데이트 목록 제공 |
| 장애인지 설정 문제인지 모름 | 우측 시스템 상태 카드에서 서비스/API/저장소/자동 작업 상태와 마지막 점검 시간 표시 |
| 문서만으로 해결되지 않음 | 도움말 봇 CTA와 의견 보내기 버튼으로 대화형 지원 및 피드백 제공 |

## 2. 화면 범위와 전제

- 이 문서는 첨부 이미지와 `/Users/user/personal/ai-chat-workspace/docs/personal-agent-platform-prd.md` 기준의 PC 웹 화면 상세다.
- 소유 파일은 이 문서 하나이며, 좌측 글로벌 내비게이션은 공통 셸로 간주한다.
- 화면명은 한국어 `도움말`, 영문 라우트/내부 개념은 `Help`를 사용한다.
- MVP는 문서 탐색, 검색, 문서 상세, 명령어 복사, 도움말 봇 진입, 최근 업데이트, 키보드 단축키, 시스템 상태 표시를 포함한다.
- Dev Mode 튜토리얼은 로컬 서버/TUI/MCP/자체 API token의 진입 문서 역할을 한다. 실제 토큰 발급/폐기는 `설정 > 개발자` 또는 연결된 Dev Mode 설정 화면에서 처리한다.
- 문서 원문은 CMS 또는 정적 help 문서로 관리할 수 있으나, 화면에서는 `help_article` 객체로 조회되는 것으로 본다.

## 3. 정보 구조

### 3.1 전체 레이아웃

PC 기준 4개 주요 영역으로 구성한다.

| 영역 | 구성 | 역할 |
| --- | --- | --- |
| 좌측 글로벌 내비게이션 | 허브명, 알림, 오늘, 주제, 맡긴 일, 기억, 에이전트, 연결, 스크랩, 캘린더, 할 일, 파일, 설정, 도움말, 사용자 카드 | 앱 전체 이동. 현재 메뉴 `도움말` 활성화. |
| 중앙 상단 | 제목 `도움말`, 보조 설명, `의견 보내기`, 검색창 | 도움말 화면의 목적 안내, 검색, 피드백 진입. |
| 중앙 콘텐츠 3열 | 가이드 IA, 문서 카드 목록, 문서 상세 | 문서 분류 탐색, 문서 선택, 실제 가이드 읽기. |
| 우측 지원 패널 | 도움말 봇, 최근 업데이트, 키보드 단축키, 시스템 상태 | 문서 외 지원, 변경 사항, 조작 힌트, 운영 상태 확인. |

첨부 화면의 중앙 콘텐츠는 좌측 `가이드` 목록, 가운데 문서 카드 목록, 오른쪽 문서 본문으로 나뉜다. 우측 지원 패널은 별도 카드 4개가 세로로 쌓인다.

### 3.3 가이드 IA 구조

화면 좌측 `가이드` 영역은 카테고리 accordion과 하위 문서 링크로 구성한다. 첨부 화면 기준 기본 노출 구조는 다음이다.

| 카테고리 | 하위 문서 | 기본 상태 | 목적 |
| --- | --- | --- | --- |
| 시작하기 | 계정과 프로필, 전체 기능 둘러보기 | 펼침 | 첫 사용자 온보딩 |
| 채팅에서 주제로 이동 | 주제 만들기, 작업 흐름 이해하기 | 펼침 | 채팅 결과를 지속 작업공간으로 승격하는 방법 안내 |
| 에이전트에게 맡기기 | 에이전트 만들기, 맡긴 일 관리 | 펼침 | agent run과 schedule의 기본 개념 안내 |
| 스크랩과 기억 | 스크랩 활용하기, 기억 저장과 연결 | 펼침 | source/memory를 나중에 재사용하는 방법 안내 |
| 모델/비용 관리 | 모델 연결하기, 비용과 요금 이해하기 | 펼침 | provider, model routing, 비용 제한 안내 |
| Dev Mode | 로컬 연동, API & 토큰, MCP 연동 | 펼침, `로컬 연동` 선택 | TUI/MCP/localhost API를 이용하는 개발자 가이드 |

선택된 문서는 파란색 배경과 텍스트로 표시한다. 카테고리 우측 chevron은 확장/접기를 제어한다.

## 4. 진입 / 종료 / 전환 동선

### 4.1 진입 동선

| 진입점 | 동작 |
| --- | --- |
| 좌측 내비게이션 `도움말` 클릭 | 최근 선택한 가이드 카테고리와 문서를 복원한다. 없으면 `시작하기 > 전체 기능 둘러보기` 또는 추천 문서를 연다. |
| 설정/연결/에이전트 화면의 도움말 링크 | 관련 카테고리와 문서를 선택한 상태로 진입한다. 예: `설정 > Dev Mode`에서 오면 `Dev Mode > 로컬 연동`. |
| 오류 toast의 `도움말 보기` | 오류 코드나 기능 영역에 매핑된 문서를 열고 본문 내 관련 섹션으로 스크롤한다. |
| 도움말 검색 딥링크 | 검색어를 입력한 상태로 진입하고 결과 목록을 표시한다. |
| 최근 업데이트 항목 클릭 | 업데이트된 문서를 열고 업데이트 배지를 강조한다. |
| 키보드 `⌘K` | 현재 화면 위에 통합 검색 command palette를 열며, 도움말 결과를 포함한다. |
| URL 직접 접근 | `articleSlug`가 있으면 해당 문서 상세를 연다. 문서가 없거나 권한이 없으면 도움말 홈으로 fallback하고 오류를 표시한다. |

### 4.2 종료 동선

| 종료 액션 | 결과 |
| --- | --- |
| 좌측 메뉴 이동 | 검색어, 선택 문서, 스크롤 위치를 세션 범위에서 보존한다. |
| 문서 내 관련 화면 링크 클릭 | 해당 제품 화면으로 이동한다. 예: `연결 설정하기`, `설정 > 개발자`. |
| 도움말 봇 대화 시작 | 도움말 봇 패널 또는 채팅 화면의 help scope 대화로 전환한다. |
| 시스템 상태 `상세 보기` 클릭 | 상태 상세 페이지 또는 운영 상태 모달로 이동한다. |
| 의견 보내기 완료 | 현재 문서/검색어/선택 카테고리를 포함해 피드백을 저장하고 원래 화면에 머문다. |
| `esc` 입력 | 검색 palette, 봇 패널, 피드백 모달, 코드 복사 toast 같은 overlay를 닫는다. overlay가 없으면 동작하지 않는다. |

### 4.3 내부 전환

| 전환 | 트리거 | 기대 동작 |
| --- | --- | --- |
| 검색 실행 | 검색창 입력, `⌘K`, 엔터 | 문서 카드 목록을 검색 결과로 전환하고 키워드를 하이라이트한다. |
| 카테고리 확장/접기 | 가이드 IA chevron 클릭 | 하위 문서 표시를 토글한다. 선택 문서가 접힌 카테고리 안에 있으면 선택 상태는 유지하되 카테고리를 자동 펼침한다. |
| 문서 카드 선택 | 카드 클릭 | 선택 카드 테두리/배경을 강조하고 문서 상세를 갱신한다. |
| 북마크 토글 | 카드 우하단 북마크 아이콘 클릭 | 사용자별 저장 문서 상태를 변경한다. 카드 선택 이벤트와 충돌하지 않아야 한다. |
| 링크 복사 | 카드 하단 링크 아이콘 클릭 | 문서 공유 링크를 클립보드에 복사하고 toast를 표시한다. |
| 코드 복사 | 코드 블록 우측 복사 버튼 클릭 | 해당 명령어만 복사한다. 성공 시 버튼 상태를 짧게 `복사됨`으로 바꾼다. |
| 도움말 봇 시작 | `도움말 봇에 질문하기` 클릭 | 현재 문서 context를 포함해 help bot conversation을 시작한다. |
| 최근 업데이트 모두 보기 | `모두 보기` 클릭 | 업데이트 목록 모달 또는 업데이트 전용 help 필터를 연다. |
| 상태 상세 보기 | 시스템 상태 `상세 보기` 클릭 | 서비스별 상태, incident, 점검 이력을 표시한다. |

## 5. 핵심 시나리오

### 5.1 사용자가 필요한 문서를 검색해서 읽음

1. 사용자가 도움말 화면에 진입한다.
2. 검색창 `무엇을 알고 싶나요?`에 `MCP`, `워크스페이스`, `비용` 같은 키워드를 입력한다.
3. 시스템은 제목, 본문, 태그, 명령어, 업데이트 노트를 통합 검색한다.
4. 중앙 문서 카드 목록이 관련도순으로 갱신된다.
5. 사용자가 문서 카드를 클릭한다.
6. 문서 상세에 제목, 카테고리, 읽기 시간, 최종 업데이트, 본문이 표시된다.
7. 사용자는 본문에서 필요한 단계와 명령어를 확인한다.

### 5.2 Dev Mode 로컬 연동 문서를 따라 TUI에서 워크스페이스를 조회함

1. 사용자가 가이드 IA에서 `Dev Mode > 로컬 연동`을 선택한다.
2. 문서 목록에서 `TUI에서 워크스페이스 조회하기` 카드를 선택한다.
3. 상세 본문에서 로컬 서버 실행 명령어 `aihub server start`를 복사한다.
4. 로컬 서버가 실행되면 endpoint `http://localhost:8787`을 확인한다.
5. 사용자가 `aihub tui` 명령어를 복사해 TUI를 연다.
6. TUI에서 `aihub workspace list`를 실행해 워크스페이스 목록을 조회한다.
7. 시스템은 문서 안에서 방향키/Enter 조작 팁과 보안 주의사항을 함께 제공한다.

### 5.3 문서만으로 해결되지 않아 도움말 봇에 질문함

1. 사용자가 문서 본문을 읽다가 이해되지 않는 지점이 생긴다.
2. 우측 `도움말 봇에 질문하기` 버튼을 클릭한다.
3. 시스템은 현재 문서 ID, 선택 섹션, 검색어, 사용자 환경 정보를 help bot context로 전달한다.
4. 도움말 봇은 문서 근거를 바탕으로 추가 설명과 다음 액션을 제시한다.
5. 봇 답변이 제품 화면 이동을 요구하면 `설정 열기`, `연결 화면으로 이동`, `상태 상세 보기` 같은 CTA를 제공한다.

### 5.4 최근 업데이트에서 신규 가이드를 확인함

1. 사용자가 우측 `최근 업데이트` 카드에서 `Dev Mode 가이드 추가`를 확인한다.
2. 항목의 `신규` 배지와 날짜 `2024. 5. 18`을 보고 최신 문서임을 판단한다.
3. 업데이트 항목을 클릭하면 관련 문서 상세가 열린다.
4. 문서 상세의 최종 업데이트 일자와 업데이트 사유가 표시된다.
5. `모두 보기`를 누르면 최근 업데이트 전체 목록으로 전환된다.

### 5.5 시스템 문제가 있는지 확인함

1. 사용자가 명령어 실행이나 API 호출이 실패했다고 느낀다.
2. 우측 `시스템 상태` 카드에서 서비스/API/저장소/자동 작업 상태를 확인한다.
3. 모두 정상이면 사용자는 문서의 설정/권한/토큰 단계를 다시 확인한다.
4. 특정 항목이 장애 상태면 `상세 보기`에서 incident와 예상 복구 시간을 확인한다.
5. 도움말 봇에 질문할 때 현재 상태 정보가 context로 포함된다.

### 5.6 의견 보내기로 문서 품질을 개선함

1. 사용자가 문서 내용이 부족하거나 틀렸다고 판단한다.
2. 헤더의 `의견 보내기`를 클릭한다.
3. 시스템은 현재 문서, 선택 섹션, 검색어, 사용자 브라우저/앱 버전을 포함한 피드백 폼을 연다.
4. 사용자가 의견 유형, 설명, 스크린샷 첨부 여부를 입력한다.
5. 제출 후 피드백이 저장되고 문서 담당자가 triage할 수 있는 상태가 된다.

### 6.2 화면 헤더

| 요소 | 기능 |
| --- | --- |
| 제목 `도움말` | 현재 화면 식별. |

| `의견 보내기` | 현재 화면 또는 선택 문서에 대한 피드백 폼을 연다. |

`의견 보내기`는 문서에 대한 낮은 만족도, 오타, 누락된 단계, 명령어 오류, 화면과 문서 불일치를 받는다. 문서가 선택된 상태면 `articleId`, `sectionId`, `articleVersion`을 자동 포함한다.

### 6.3 검색바

| 요소 | 기능 |
| --- | --- |
| placeholder | `무엇을 알고 싶나요?` |
| 검색 아이콘 | 검색 입력임을 시각적으로 표시한다. |
| 단축키 배지 | `⌘K` 표시. Windows/Linux는 `Ctrl+K`로 대체 가능하다. |
| 결과 범위 | 문서 제목, 본문, 태그, 명령어, 업데이트, 시스템 상태 항목. |
| 결과 표시 | 중앙 카드 목록을 검색 결과로 바꾸고 매칭 텍스트를 하이라이트한다. |

검색은 debounce로 동작한다. 엔터 입력은 첫 번째 결과 선택 또는 전체 결과 확정으로 처리한다. 빈 검색어에서는 추천 문서 또는 현재 카테고리 문서 목록을 보여준다.

### 6.4 가이드 IA

가이드 IA는 사용자가 제품 개념을 위에서 아래로 훑는 구조다. 각 카테고리는 accordion이며 하위 문서는 클릭 가능한 링크다.

| 상태 | 표시/동작 |
| --- | --- |
| 기본 펼침 | 첨부 화면처럼 모든 주요 카테고리를 펼쳐 빠른 스캔을 돕는다. |
| 선택 문서 | 파란 배경, 파란 텍스트로 강조한다. |
| 접힘 | 하위 문서를 숨기고 chevron 방향을 바꾼다. |
| 검색 중 | 검색 결과와 관련된 카테고리를 우선 펼치고 매칭 문서를 강조한다. |
| 권한 제한 | 사용자가 접근할 수 없는 문서는 숨기거나 잠금 아이콘과 설명을 표시한다. |

카테고리와 문서 순서는 사용자의 초보자 흐름을 따른다. Dev Mode는 일반 사용자 흐름 뒤에 배치하되, 첨부 화면처럼 선택 상태에서는 하위 문서가 명확히 드러나야 한다.

### 6.5 문서 카드 목록

첨부 화면의 문서 카드 목록은 선택된 가이드 카테고리의 문서를 카드로 보여준다.

| 필드 | 표시/동작 |
| --- | --- |
| 문서 제목 | 1~2줄. 예: `OpenRouter API Key 연결하기`, `TUI에서 워크스페이스 조회하기`. |
| 배지 | `인기`, `신규` 등. 문서 상태나 추천 정도 표시. |
| 설명 | 문서 핵심 내용을 2줄로 요약. |
| 읽기 시간 | `3분 읽기`, `4분 읽기`, `2분 읽기` 등. |
| 링크 아이콘 | 문서 공유 링크 복사. |
| 북마크 아이콘 | 사용자별 저장/해제. |
| 선택 상태 | 파란 테두리와 연한 파란 배경. 상세 문서와 동기화. |

첨부 화면 기준 Dev Mode 문서 예시는 다음이다.

| 문서 | 배지 | 설명 | 읽기 시간 |
| --- | --- | --- | --- |
| OpenRouter API Key 연결하기 | 인기 | OpenRouter를 연결해 다양한 모델을 사용하는 방법 | 3분 |
| Local Codex OAuth로 로그인하기 | 신규 | 로컬 Codex 서버에 안전하게 로그인하는 방법 | 4분 |
| TUI에서 워크스페이스 조회하기 | 없음 | 터미널 UI로 내 워크스페이스와 주제를 확인하는 방법 | 2분 |
| MCP로 내 주제와 파일 접근하기 | 없음 | MCP 서버를 통해 주제와 파일을 안전하게 접근하는 방법 | 5분 |

### 6.6 문서 상세

문서 상세는 선택한 문서를 실제 실행 가능한 수준으로 읽는 영역이다. 첨부 화면의 선택 문서는 `TUI에서 워크스페이스 조회하기`다.

| 요소 | 기능 |
| --- | --- |
| 제목 | 문서 제목. |
| 메타데이터 | 카테고리 breadcrumb, 읽기 시간, 최종 업데이트. |
| 요약 | 문서가 해결하는 문제와 기대 결과를 한 문단으로 설명. |
| 본문 섹션 | `시작하기`, 단계별 절차, 팁, 보안 주의사항. |
| 번호 단계 | 파란 원형 번호로 순서를 명확히 표시. |
| 코드 블록 | 명령어, endpoint, 터미널 출력 예시. |

문서 본문은 화면 안에서 독립 스크롤될 수 있다. 긴 문서는 우측에 목차를 추가할 수 있지만, 첨부 화면 MVP에서는 우측 지원 패널을 유지한다.

### 6.7 문서 메타데이터

| 메타데이터 | 예시 | 요구사항 |

## 7. Dev Mode 튜토리얼 상세

첨부 화면의 선택 문서 `TUI에서 워크스페이스 조회하기`를 기준으로 Dev Mode 로컬 연동 튜토리얼을 정의한다.

### 7.1 문서 목적

이 문서는 사용자가 터미널 UI(TUI)를 통해 로컬 환경에서 내 워크스페이스와 주제를 빠르게 확인하도록 돕는다. Dev Mode 사용자는 웹 UI를 열지 않고도 로컬 서버, TUI, workspace list 명령어로 현재 허브의 작업공간 상태를 확인할 수 있어야 한다.

### 7.2 전제 조건

| 조건 | 설명 |
| --- | --- |
| Dev Mode 활성화 | 설정 또는 연결 화면에서 Dev Mode 접근이 허용되어 있어야 한다. |
| 로컬 서버 설치 | `aihub` CLI가 설치되어 있어야 한다. |
| 인증 상태 | Local Codex OAuth 또는 자체 API token 인증이 완료되어 있어야 한다. |
| endpoint | 기본값은 `http://localhost:8787`. |
| 네트워크 | 로컬 loopback 접근만 필요. 외부 노출은 금지. |

### 7.3 단계별 본문

| 단계 | 화면 표시 | 동작 |
| --- | --- | --- |
| 1 | `로컬 서버가 실행 중인지 확인합니다.` | `aihub server start` 코드 블록과 복사 버튼 표시. 기본 endpoint `http://localhost:8787` 링크 표시. |
| 2 | `터미널 UI를 엽니다.` | `aihub tui` 코드 블록과 복사 버튼 표시. |
| 3 | `워크스페이스 목록을 조회합니다.` | 검은색 터미널 예시 안에 `aihub workspace list`와 결과 테이블 표시. |

터미널 예시는 다음 정보를 포함한다.

| 컬럼 | 예시 | 설명 |
| --- | --- | --- |
| NAME | 도쿄 여행, 투자 리서치, 블로그 아이디어 | 사용자에게 보이는 워크스페이스명. |
| SLUG | tokyo-trip, invest, blog-ideas | CLI/API에서 쓰는 식별자. |
| TOPICS | 8, 6, 5 | 연결된 주제 수. |
| UPDATED | 2분 전, 15분 전, 1시간 전 | 마지막 갱신 시각. |

### 7.4 팁 박스

팁 박스는 명령어 다음에 노출한다.

| 요소 | 내용 |
| --- | --- |
| 아이콘 | 전구 아이콘 |
| 문구 | `화살표 ↑/↓ 로 선택하고 Enter 로 상세 보기를 열 수 있습니다.` |
| 목적 | 사용자가 TUI 내부 조작을 바로 이해하게 함 |

### 7.5 보안 주의사항

보안 주의사항은 빨간색 경고 카드로 표시한다.

| 요소 | 내용 |
| --- | --- |
| 제목 | `보안 주의사항` |
| 본문 | `로컬 엔드포인트는 외부에 노출하지 마세요. VPN 또는 SSH 터널 사용을 권장합니다.` |
| 배지 | `로컬 전용`, `포트: 8787`, `인증 필요 없음` |

`인증 필요 없음` 배지는 실제 정책과 충돌하지 않아야 한다. 로컬 loopback에서만 인증 생략이 가능한 구조라면 배지 설명에 `localhost 한정`을 붙이거나 문구를 조정해야 한다.

### 7.6 관련 문서 연결

Dev Mode 로컬 연동 문서 하단 또는 문서 카드 목록에서 다음 문서로 이동할 수 있어야 한다.

| 관련 문서 | 이동 이유 |
| --- | --- |
| Local Codex OAuth로 로그인하기 | TUI 실행 전 인증이 필요한 경우 |
| 자체 API 토큰 만들기 | 외부 스크립트나 로컬 도구에서 API를 호출해야 하는 경우 |
| MCP로 내 주제와 파일 접근하기 | IDE/agent tool에서 workspace와 file을 접근해야 하는 경우 |
| 자동 작업 권한 설정하기 | TUI나 API로 schedule/run을 만들려는 경우 |

## 8. Edge Case

### 8.1 검색/탐색

| 상황 | 처리 |
| --- | --- |
| 검색 결과 없음 | `검색 결과가 없습니다.`와 필터 초기화, 도움말 봇 질문 CTA를 표시한다. |
| 짧은 검색어 | 1글자 검색은 로컬 최근 문서 우선, 2글자 이상부터 서버 검색을 실행한다. |
| 오타 검색 | 유사어/초성/영문 alias를 검색한다. 예: `tui`, `터미널`, `terminal`. |
| 문서 삭제/이동 | 이전 slug 접근 시 새 slug로 redirect하거나 도움말 홈으로 fallback한다. |
| 카테고리 접힘 상태와 선택 문서 불일치 | 선택 문서가 속한 카테고리를 자동으로 펼친다. |
| 검색 중 카테고리 클릭 | 검색어를 유지할지 해제할지 명확히 한다. 기본은 검색어 해제 후 카테고리 문서 표시. |

### 8.2 문서/명령어

| 상황 | 처리 |
| --- | --- |
| 문서 조회 실패 | 문서 영역에 재시도 버튼과 캐시된 이전 버전 표시 여부를 제공한다. |
| 카드 목록은 성공, 상세 실패 | 카드 선택 상태는 유지하고 상세 영역만 오류 상태로 표시한다. |
| 코드 복사 실패 | clipboard 권한 오류를 표시하고 사용자가 직접 선택할 수 있게 코드 블록을 focus한다. |
| 명령어가 사용자 환경과 다름 | OS, 설치 상태, 권한에 따라 대체 명령어 또는 전제 조건을 표시한다. |
| 민감 정보 포함 명령어 | 토큰 원문을 표시하지 않고 placeholder와 설정 화면 링크를 제공한다. |
| 최종 업데이트가 오래됨 | 문서 상단에 `검토 필요` 또는 `오래된 문서일 수 있음` 배지를 표시한다. |
| 업데이트 도중 문서 버전 변경 | 사용자가 읽는 중에는 현재 버전을 유지하고, 상단에 새 버전 알림과 새로고침 CTA를 표시한다. |
| 문서 본문과 카드 메타데이터 불일치 | `updatedAt`, `readTimeMinutes`, `statusBadge`는 같은 article version 기준으로 조회한다. |

### 8.3 Dev Mode

| 상황 | 처리 |
| --- | --- |
| Dev Mode 권한 없음 | 문서는 읽을 수 있게 하되 실행 CTA는 비활성화하고 권한 요청/설정 이동을 제공한다. |
| `aihub` CLI 미설치 | 설치 문서와 연결하고 현재 튜토리얼은 전제 조건 미충족 상태로 표시한다. |
| 로컬 서버 미실행 | `aihub server start` 단계를 강조하고 시스템 상태와 구분한다. |
| 포트 8787 충돌 | 대체 포트 설정 문서 또는 `--port` 옵션을 안내한다. |
| 인증 만료 | Local Codex OAuth 재로그인 문서로 연결한다. |
| workspace 목록 없음 | 빈 결과 예시와 `주제 만들기` 또는 `워크스페이스 생성` 안내를 표시한다. |
| 외부 노출 위험 | localhost가 아닌 host로 접근 중이면 보안 경고를 강화한다. |

### 8.4 우측 지원 패널

| 상황 | 처리 |
| --- | --- |
| 도움말 봇 사용 불가 | CTA를 비활성화하고 시스템 상태 또는 문의 채널을 표시한다. |
| 도움말 봇 답변 근거 부족 | 답변에 참조 문서/섹션을 표시하고, 근거 없는 추정은 설정 화면 이동이나 운영 문의로 넘긴다. |
| 최근 업데이트 없음 | `최근 업데이트가 없습니다.`와 전체 문서 보기 링크를 표시한다. |
| 단축키 충돌 | 앱 전역 단축키 설정 또는 브라우저 기본 동작과 충돌하는 항목을 비활성/대체 표기한다. |
| 시스템 상태 조회 실패 | 마지막 성공 점검 시간과 재시도 버튼을 표시한다. |
| 일부 장애 | 전체 상태를 `일부 지연`으로 바꾸고 장애 항목을 상단에 정렬한다. |
| 외부 provider 장애 | 플랫폼 내부 `서비스/API/저장소/자동 작업` 상태와 OpenRouter, MCP, OAuth 같은 외부 연결 상태를 구분해 표시한다. |

### 8.5 권한/접근성/반응형

| 상황 | 처리 |
| --- | --- |
| 읽기 권한 제한 문서 | 잠금 아이콘과 접근 요청 CTA를 표시한다. |
| 키보드 탐색 | 검색, 카테고리, 카드, 본문 링크, 복사 버튼, 우측 카드가 tab 순서대로 이동 가능해야 한다. |
| 스크린리더 | 코드 복사 버튼, 상태 배지, 신규 배지에 aria-label을 제공한다. |
| 작은 화면 | 가이드 IA와 우측 지원 패널을 접고 문서 목록/상세를 탭 또는 drawer로 전환한다. |
| 긴 코드 | 가로 스크롤을 제공하되 복사 버튼 위치는 고정한다. |

### 8.6 자체 리뷰 체크

nested subagent 리뷰가 실패하거나 실행할 수 없는 환경에서도 개발 착수 전 아래 항목을 확인한다.

| 리뷰 포인트 | 확인 내용 |
| --- | --- |
| 첨부 화면 요소 누락 | 검색, 가이드 IA, 문서 카드, 문서 메타, 코드 복사, 팁, 보안, 봇, 업데이트, 단축키, 상태가 모두 요구사항에 포함됐는지 확인 |
| 클릭 이벤트 충돌 | 문서 카드 선택, 링크 복사, 북마크 토글이 서로 전파되지 않는지 확인 |
| Dev Mode 보안 문구 | `인증 필요 없음`과 실제 인증 정책이 충돌하지 않는지 확인 |
| 시스템 상태와 로컬 상태 구분 | 플랫폼 장애와 사용자 로컬 서버 미실행을 같은 오류로 표시하지 않는지 확인 |
| 검색 결과와 IA 선택 상태 | 검색 결과 문서를 선택한 뒤 가이드 카테고리 강조가 올바른지 확인 |
| 날짜/시간 표기 | 업데이트 날짜와 마지막 점검 시간이 사용자 locale/timezone 기준인지 확인 |
| 권한별 CTA | 읽기 전용 사용자가 토큰 발급/설정 변경 CTA를 누를 때 적절히 차단되는지 확인 |

## 9. 데이터 필드 / API 힌트

### 9.1 화면 초기 데이터

`GET /api/help`

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| activeHub | object | 현재 허브 정보. |
| navigation | array | 공통 사이드바 메뉴와 권한. |
| guideTree | array | 가이드 IA 카테고리와 하위 문서. |
| featuredArticles | array | 기본 또는 선택 카테고리의 문서 카드 목록. |
| selectedArticle | object | 현재 선택된 문서. 없으면 추천 문서. |
| recentUpdates | array | 최근 업데이트 목록. |
| shortcuts | array | 키보드 단축키 목록. |
| systemStatus | object | 전체 상태와 서비스별 상태. |
| permissions | object | help bot, feedback, dev mode CTA 사용 가능 여부. |

초기 API는 한 번에 화면을 구성할 수 있게 하되, 검색/상태/봇은 별도 API로 분리할 수 있다.

### 9.2 문서 검색/조회

| API | 용도 |
| --- | --- |
| `GET /api/help/articles?categoryId=&query=&tag=&page=` | 문서 카드 목록 조회와 검색. |
| `GET /api/help/articles/{articleSlug}` | 문서 상세 조회. |
| `POST /api/help/articles/{articleId}/bookmark` | 문서 북마크 설정. |
| `DELETE /api/help/articles/{articleId}/bookmark` | 문서 북마크 해제. |
| `POST /api/help/articles/{articleId}/copy-link` | 공유 링크 생성 또는 복사 이벤트 기록. |
| `POST /api/help/feedback` | 의견 보내기 제출. |

### 9.3 도움말 봇/상태/업데이트

| API | 용도 |
| --- | --- |
| `POST /api/help/bot/conversations` | 도움말 봇 대화 생성. |
| `POST /api/help/bot/messages` | 도움말 봇 메시지 전송. |
| `GET /api/help/updates?limit=` | 최근 업데이트 조회. |
| `GET /api/system/status` | 서비스/API/저장소/자동 작업 상태 조회. |
| `GET /api/system/incidents` | 장애/점검 이력 조회. |
| `GET /api/connections/status-summary` | 외부 provider, MCP, OAuth 연결 상태 요약 조회. |

### 9.5 이벤트/분석

| 이벤트 | 목적 |
| --- | --- |
| `help_search_submitted` | 검색어, 결과 수, 선택 여부 분석. |
| `help_article_selected` | 어떤 문서가 많이 읽히는지 분석. |
| `help_code_copied` | 어떤 명령어가 실제 실행 후보인지 분석. 원문 저장 금지. |
| `help_bot_started` | 문서로 해결되지 않은 영역 파악. |
| `help_bot_answer_rated` | 도움말 봇 답변의 유용성, 근거 문서 적합성 분석. |

민감한 명령어, 토큰, endpoint 원문은 분석 이벤트에 저장하지 않는다.

## 10. 수용 기준

### 10.1 레이아웃/표시

- 좌측 글로벌 내비게이션에서 `도움말` 메뉴가 활성 상태로 표시된다.
- 상단에 제목 `도움말`, 보조 설명, `의견 보내기` 버튼이 표시된다.
- 검색창에는 `무엇을 알고 싶나요?` placeholder와 `⌘K` 단축키 배지가 표시된다.
- 중앙 콘텐츠는 가이드 IA, 문서 카드 목록, 문서 상세의 3열 구조로 표시된다.
- 우측 지원 패널에는 도움말 봇, 최근 업데이트, 키보드 단축키, 시스템 상태 카드가 표시된다.

### 10.2 검색/가이드 IA

- 검색어 입력 시 문서 제목, 본문, 태그, 명령어를 대상으로 결과가 표시된다.
- 검색 결과 없음 상태에서 도움말 봇 CTA와 필터 초기화 동작을 제공한다.
- 가이드 카테고리는 확장/접기가 가능하다.
- 선택된 문서는 가이드 IA와 문서 카드 목록 양쪽에서 시각적으로 구분된다.
- Dev Mode 카테고리에는 `로컬 연동`, `API & 토큰`, `MCP 연동` 하위 문서가 표시된다.

### 10.3 문서 상세/메타데이터

- 문서 상세에는 제목, categoryPath, 읽기 시간, 최종 업데이트 일자가 표시된다.
- `TUI에서 워크스페이스 조회하기` 문서는 로컬 서버 실행, TUI 실행, workspace list 조회의 3단계를 포함한다.
- 문서에는 endpoint `http://localhost:8787`, 팁 박스, 보안 주의사항 카드가 표시된다.
- 코드 블록은 각 블록별 복사 버튼을 제공한다.
- 복사 성공/실패 상태가 사용자에게 명확히 표시된다.

### 10.4 우측 지원 기능

- 도움말 봇 CTA를 누르면 현재 문서 context를 포함한 help bot conversation이 시작된다.
- 최근 업데이트 카드에는 신규 배지, 제목, 날짜, `모두 보기`가 표시된다.
- 키보드 단축키 카드에는 `⌘K`, `⌘/`, `⌘J`, `⌘.`, `esc`가 표시된다.
- 시스템 상태 카드에는 서비스, API, 저장소, 자동 작업 상태와 마지막 점검 시간이 표시된다.
- 시스템 상태 `상세 보기`를 누르면 상태 상세 또는 incident 목록으로 이동한다.

### 10.5 상태/권한/접근성

- 문서 목록, 문서 상세, 시스템 상태는 독립 로딩/오류 상태를 가진다.
- Dev Mode 권한이 없는 사용자는 실행 CTA가 제한되며 설정/권한 요청 안내를 받는다.
- 키보드만으로 검색, 가이드 선택, 문서 카드 선택, 코드 복사, 우측 카드 CTA를 사용할 수 있다.
- 복사 버튼, 상태 배지, 신규 배지는 스크린리더가 의미를 읽을 수 있는 label을 가진다.
- 모바일/좁은 화면에서는 가이드 IA와 우측 패널이 drawer 또는 탭으로 접힌다.

## 11. 오픈 질문

| 질문 | 후보/검토 방향 |
| --- | --- |
| 도움말 문서는 정적 markdown으로 관리할지 CMS/API로 관리할지 | MVP는 정적 문서 + 검색 인덱스, 이후 CMS 전환 가능. |
| 도움말 봇은 전역 채팅과 같은 conversation으로 남길지 별도 help scope로 둘지 | 기본은 help scope. 사용자가 원할 때 전역/주제 대화로 승격. |
| Dev Mode 문서의 `인증 필요 없음` 배지는 실제 보안 정책과 맞는지 | localhost 한정 인증 생략인지, token 필수인지 정책 확인 필요. |
| `⌘.` 다음 항목 단축키의 정확한 대상은 무엇인지 | 검색 결과 다음 항목, 문서 카드 다음 항목, 본문 다음 섹션 중 결정 필요. |
| 시스템 상태는 자체 status API인지 외부 status page embed인지 | MVP는 내부 API, 공개 상태 페이지가 생기면 링크 병행. |
| 최근 업데이트 `신규` 배지는 며칠 동안 유지할지 | 7일, 14일, 사용자가 읽을 때까지 중 하나 선택 필요. |
| 문서 북마크는 도움말 화면 안에서만 쓸지 전역 즐겨찾기에 들어갈지 | MVP는 도움말 전용, 이후 사용자 저장 항목으로 통합 가능. |
| 검색 결과에 시스템 상태와 업데이트를 문서와 같은 목록에 섞을지 분리할지 | 통합 검색은 섞되 타입 배지를 명확히 표시. |
| Dev Mode 명령어의 OS별 차이를 어떻게 제공할지 | macOS/Linux/Windows 탭 또는 자동 감지 기반 variant 필요. |
| 도움말 피드백은 어떤 관리 도구로 연결할지 | 내부 issue, support queue, 문서 backlog 중 운영 방식 결정 필요. |
